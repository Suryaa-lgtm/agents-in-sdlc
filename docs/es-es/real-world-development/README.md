Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante escenarios realistas, una aplicación completa y una lista de trabajo compartida. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres una persona desarrolladora nueva en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. La lista de trabajo de tu equipo ya está registrada como incidencias de GitHub y lista para que las abordes. Incluye trabajo de nuevas funcionalidades, como filtros y paginación, junto con mejoras de calidad, como accesibilidad y estándares de programación.

## Elige tu entorno

GitHub Copilot te acompaña allá donde trabajes. Elige el entorno que se ajuste a tu forma de crear. Cada taller empieza con su propia configuración y utiliza el mismo escenario de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Utiliza el asistente con agentes en tu terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades de agente, agentes personalizados, Playwright MCP, Agent Merge y comandos prácticos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia los modos de sesión, colabora en lienzos y gestiona incidencias y solicitudes de incorporación de cambios en la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asincrónico, guía su trabajo, supervisa su progreso y revisa las solicitudes de incorporación de cambios que abra.

### [Visual Studio Code][vscode]

Utiliza GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
