通过真实场景、完整应用和共享待办事项，探索 GitHub Copilot 在软件开发生命周期中的应用。你将迭代地规划更改、创建代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，主营面向开发者主题的桌游众筹。团队的待办事项已经以 GitHub issues 的形式整理完毕，可供你直接认领。其中既包括筛选和分页等功能开发，也包括无障碍性和编码规范等质量改进。

## 选择运行环境

无论在什么地方工作，GitHub Copilot 都能为你提供支持。请选择与你的构建方式相符的环境。每个工作坊都会从自己的环境设置开始，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。通过 Plan 和 Autopilot 模式、自定义指令、技能、自定义智能体、Playwright MCP、Agent Merge 以及实用的斜杠命令完成工作。

### [GitHub Copilot app][app]

运行并行智能体会话，切换会话模式，在画布上协作，并管理桌面应用中的 GitHub issues 和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub issues 分配给异步智能体，引导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。在不离开编辑器的情况下，使用 Copilot Chat 的智能体模式、MCP 服务器和自定义智能体。
